# FDD (Barbershop booking platform) 

## General description
A fully functional appointment booking system for a barbershop.

## Functional requirements
- Authentication for admin;
- Calendar with availability;
- Booking confirmation in email;
- Admin-dashboard with overview of past, present & future bookings;
- Able to select which (combination of) service you want to book including costs;
  - Hair cuts;
  - Beard trims or shaves;
  - Washing hair.
- Descriptions of each service;
- Ability to see previous work in a photo gallery display.

## Non-functional requirements

### Performance
The application should load within 2 seconds under normal network conditions.

### Usability
The user interface should be accessible to people with disabilities (LightHouse).

### Security
The login data and posts should be stored in a secure way.

### Responsiveness 
The app should be usable on the most popular screensizes (laptop, desktop, tablet, mobile).

# Refinement of each requirement
### Must Have:
- Calendar with availability;
- A secure booking database;
- Barber contact information;
- Ability to choose which treatment(s) you want to book;
- The application should load within 2 seconds under normal network conditions;
- The login data and posts should be stored in a secure way.

### Should Have:
- Booking confirmation in email;
- A one-pager for information and the bookings;
- Authentication for admin;
- Admin-dashboard with overview of past, present & future bookings;
- The user interface should be accessible to people with disabilities (LightHouse).

### Could Have:
- Descriptions about what each service provides;
- A gallery display of the barber's previous work;
- The app should be usable on the most popular screensizes (laptop, desktop, tablet, mobile).

### Won't Have:
- Bright or otherwise overstimulating colors.
